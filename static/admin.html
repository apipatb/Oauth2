System Information

🚀 OAuth2 Authorization Server v2.0

Features:
✓ JWT-based tokens
✓ Database storage (SQLite/PostgreSQL)
✓ PKCE support
✓ Token revocation
✓ Rate limiting
✓ Password hashing (bcrypt)
✓ Client credentials grant
✓ Authorization code grant
✓ Refresh token grant

Endpoints:
/oauth/authorize - Authorization endpoint
/oauth/token - Token endpoint
/oauth/revoke - Token revocation
/api/userinfo - Protected user info
/api/data - Protected data
/api/public - Public endpoint
/admin/user/register - User registration
/admin/client/create - Client creation
